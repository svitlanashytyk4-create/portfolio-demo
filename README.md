# Portfolio demo

Сайт-портфоліо Світлани, UI-дизайнерки. Next.js (App Router) + TypeScript + Tailwind CSS.

- План сайту: [docs/site-plan.md](docs/site-plan.md)
- Наступний крок: дизайн-токени й компоненти, потім перший екран.

## Запуск

```bash
npm install
npm run dev
```

Відкрий http://localhost:3000.
